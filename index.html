🛴 Electric Scooter: Battery Connect Transient

What happens in the first milliseconds after you switch on an electric scooter? The battery voltage hits the motor controller as a sudden step. The cable inductance and the controller’s DC-link capacitor can make it overshoot and damage the MOSFETs. We analyse it with the Laplace transform.

Laplace steps (for your presentation)

Time domain (KVL): L·di/dt + R·i + (1/C)∫i dt = V·u(t)
Laplace (zero initial conditions): (sL + R + 1/sC)·I(s) = V/s
Vc(s) = I(s)/(sC) ⇒ H(s) = Vc/Vin = 1 / (LC·s² + RC·s + 1)
H(s) = ωn² / (s² + 2ζωn·s + ωn²), ωn = 1/√(LC), ζ = (R/2)·√(C/L)
Vc(s) = V·ωn² / [ s (s² + 2ζωn·s + ωn²) ] → partial fractions → inverse Laplace → vc(t)
  • ζ < 1 (underdamped): complex poles, VBUS overshoots and rings. ζ = 1: fastest rise with no overshoot. ζ > 1: smooth but slower.
  • The controller’s MOSFETs have a maximum voltage. The orange line is that rating, so an overshoot above it can destroy them.
  • Pre-charge: real EVs connect the battery through a resistor first. That raises R, which raises ζ, so the spike disappears. Try the “With pre-charge” button.
  • The motor winding is only R + L, so it is not part of this RLC stage. This analysis covers the DC input side of the controller.
  • Poles in the left half-plane mean the circuit is stable. Lower R moves poles toward the jω axis (more ringing).
  • The dashed red line is the final value V (Final Value Theorem: lim s→0 of s·Vc(s) = V).
